Bank Management System

A console-based Bank Management System developed using C++.

This project demonstrates Object-Oriented Programming (OOP), STL containers and algorithms, and input validation.

Features

- Create new bank accounts.
- Display all bank accounts.
- Search for an account by ID.
- Deposit money into an account.
- Withdraw money with balance validation.
- Delete an account.
- Find the account with the highest balance.
- Prevent duplicate account IDs.
- Validate numeric user input.

Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- "vector" for storing bank accounts.
- "find_if" for searching accounts.
- "max_element" for finding the account with the highest balance.
- "numeric_limits" for input validation.

How to Run

1. Clone or download this repository.
2. Open "BankManagementSystem.cpp" in a C++ IDE.
3. Compile the source file using a C++ compiler.
4. Run the compiled program.

Note

Account data is stored in memory and is not saved permanently after the program exits.
